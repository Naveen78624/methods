Java String Methods Cheat Sheet

Essential methods for String manipulation in Java

Basic Information Methods

length()
Arguments: 0

Returns the length of the string.

String s = "hello";
int len = s.length();
System.out.println(len); 
// Output: 5
isEmpty()
Arguments: 0

Checks if the string is empty (length is 0).

String s1 = "";
String s2 = "abc";
System.out.println(s1.isEmpty()); 
// Output: true
System.out.println(s2.isEmpty()); 
// Output: false
isBlank()
Arguments: 0

Checks if the string is empty or contains only whitespace characters (Java 11+).

String s1 = "   ";
String s2 = "abc";
System.out.println(s1.isBlank()); 
// Output: true
System.out.println(s2.isBlank()); 
// Output: false

Character & Code Point Access Methods

charAt(int index)
Arguments: 1

Returns the character at the specified index.

String s = "Java";
char c = s.charAt(2);
System.out.println(c); 
// Output: v
codePointAt(int index)
Arguments: 1

Returns the Unicode code point at the specified index.

String s = "Hello\uD83D\uDE00World"; // Contains a smiley emoji (surrogate pair)
int codePoint = s.codePointAt(5); // Index of the start of the emoji
System.out.println(codePoint); 
// Output: 128512
codePointBefore(int index)
Arguments: 1

Returns the Unicode code point before the specified index.

String s = "Hello\uD83D\uDE00World";
int codePoint = s.codePointBefore(7); // Index after the emoji (surrogate pair ends at 6)
System.out.println(codePoint); 
// Output: 128512
codePointCount(int beginIndex, int endIndex)
Arguments: 2

Returns the number of Unicode code points in the specified text range.

String s = "Hello\uD83D\uDE00World";
int count = s.codePointCount(0, s.length());
System.out.println(count); 
// Output: 11 (10 chars + 1 emoji)
offsetByCodePoints(int index, int codePointOffset)
Arguments: 2

Returns the index within this string that is offset by `codePointOffset` code points starting from `index`.

String s = "Hello\uD83D\uDE00World";
int newIndex = s.offsetByCodePoints(0, 6); // Offset by 6 code points from index 0
System.out.println(newIndex); 
// Output: 7 (after 'o' and the 2-char emoji)

Comparison Methods

equals(Object anObject)
Arguments: 1

Checks if this string is equal to the specified object. Returns true if they are equal.

String s1 = "hello";
String s2 = "hello";
String s3 = "world";
System.out.println(s1.equals(s2)); 
// Output: true
System.out.println(s1.equals(s3)); 
// Output: false
equalsIgnoreCase(String anotherString)
Arguments: 1

Compares this String to another String, ignoring case considerations.

String s1 = "Hello";
String s2 = "hello";
System.out.println(s1.equalsIgnoreCase(s2)); 
// Output: true
compareTo(String anotherString)
Arguments: 1

Compares two strings lexicographically. Returns a negative integer, zero, or a positive integer as this object is less than, equal to, or greater than the specified object.

String s1 = "apple";
String s2 = "banana";
String s3 = "apple";
System.out.println(s1.compareTo(s2)); 
// Output: (negative value)
System.out.println(s1.compareTo(s3)); 
// Output: 0
compareToIgnoreCase(String str)
Arguments: 1

Compares two strings lexicographically, ignoring case differences.

String s1 = "Apple";
String s2 = "apple";
System.out.println(s1.compareToIgnoreCase(s2)); 
// Output: 0
contentEquals(CharSequence cs)
Arguments: 1

Compares this string to the specified CharSequence. Returns true if they represent the same sequence of characters.

String s = "test";
StringBuilder sb = new StringBuilder("test");
System.out.println(s.contentEquals(sb)); 
// Output: true
contentEquals(StringBuffer sb)
Arguments: 1

Compares this string to the specified StringBuffer. Returns true if they represent the same sequence of characters.

String s = "example";
StringBuffer sb = new StringBuffer("example");
System.out.println(s.contentEquals(sb)); 
// Output: true
regionMatches(int toffset, String other, int ooffset, int len)
Arguments: 4

Tests if a region of this string matches a region of another string.

String s1 = "HelloWorld";
String s2 = "loWo";
boolean match = s1.regionMatches(3, s2, 0, 4); // Compare "loWo" from s1 (index 3) with s2
System.out.println(match); 
// Output: true
regionMatches(boolean ignoreCase, int toffset, String other, int ooffset, int len)
Arguments: 5

Same as above but can ignore case.

String s1 = "HelloWorld";
String s2 = "world";
boolean match = s1.regionMatches(true, 5, s2, 0, 5); // ignore case, start s1 at index 5, start s2 at 0, compare 5 chars
System.out.println(match); 
// Output: true

Search & Indexing Methods

indexOf(int ch)
Arguments: 1

Returns the index of the first occurrence of the specified character.

String s = "banana";
int index = s.indexOf('a');
System.out.println(index); 
// Output: 1
indexOf(int ch, int fromIndex)
Arguments: 2

Returns the index of the first occurrence of the specified character, starting the search at the specified index.

String s = "banana";
int index = s.indexOf('a', 2); // Search 'a' from index 2
System.out.println(index); 
// Output: 3
indexOf(String str)
Arguments: 1

Returns the index of the first occurrence of the specified substring.

String s = "hello world";
int index = s.indexOf("world");
System.out.println(index); 
// Output: 6
indexOf(String str, int fromIndex)
Arguments: 2

Returns the index of the first occurrence of the specified substring, starting the search at the specified index.

String s = "hello world hello";
int index = s.indexOf("hello", 1); // Start search from index 1
System.out.println(index); 
// Output: 12
lastIndexOf(int ch)
Arguments: 1

Returns the index of the last occurrence of the character.

String s = "banana";
int index = s.lastIndexOf('a');
System.out.println(index); 
// Output: 3
lastIndexOf(int ch, int fromIndex)
Arguments: 2

Searches backward for the last occurrence of the character, starting from a given index.

String s = "banana";
int index = s.lastIndexOf('a', 2); // Search 'a' backward from index 2
System.out.println(index); 
// Output: 1
lastIndexOf(String str)
Arguments: 1

Returns the last index of the specified substring.

String s = "hello world hello";
int index = s.lastIndexOf("hello");
System.out.println(index); 
// Output: 12
lastIndexOf(String str, int fromIndex)
Arguments: 2

Searches backward for the last occurrence of the substring, starting from a given index.

String s = "ababa";
int index = s.lastIndexOf("aba", 2); // Search "aba" backward from index 2
System.out.println(index); 
// Output: 0
contains(CharSequence s)
Arguments: 1

Returns true if and only if this string contains the specified sequence of character values.

String s = "programming";
System.out.println(s.contains("gram")); 
// Output: true
matches(String regex)
Arguments: 1

Tells whether or not this string matches the given regular expression.

String s = "Java123";
System.out.println(s.matches("[a-zA-Z]+[0-9]+")); 
// Output: true

Substrings & Manipulation Methods

substring(int beginIndex)
Arguments: 1

Returns a new string that is a substring starting from the specified index to the end.

String s = "Java Programming";
String sub = s.substring(5);
System.out.println(sub); 
// Output: Programming
substring(int beginIndex, int endIndex)
Arguments: 2

Returns a new string that is a substring from beginIndex to endIndex - 1.

String s = "Hello World";
String sub = s.substring(0, 5);
System.out.println(sub); 
// Output: Hello
subSequence(int beginIndex, int endIndex)
Arguments: 2

Returns a new character sequence that is a subsequence of this string.

String s = "Hello World";
CharSequence subSeq = s.subSequence(0, 5);
System.out.println(subSeq); 
// Output: Hello
replace(char oldChar, char newChar)
Arguments: 2

Returns a new string resulting from replacing all occurrences of oldChar in this string with newChar.

String s = "banana";
String newS = s.replace('a', 'o');
System.out.println(newS); 
// Output: bonono
replace(CharSequence target, CharSequence replacement)
Arguments: 2

Replaces each substring of this string that matches the literal target sequence with the specified literal replacement sequence.

String s = "hello world";
String newS = s.replace("world", "Java");
System.out.println(newS); 
// Output: hello Java
replaceAll(String regex, String replacement)
Arguments: 2

Replaces all substrings that match the regex with a replacement string.

String s = "one two one";
String newS = s.replaceAll("one", "three");
System.out.println(newS); 
// Output: three two three
replaceFirst(String regex, String replacement)
Arguments: 2

Replaces the first substring matching the regex.

String s = "one two one";
String newS = s.replaceFirst("one", "three");
System.out.println(newS); 
// Output: three two one
concat(String str)
Arguments: 1

Concatenates the specified string to the end of this string.

String s1 = "Hello";
String s2 = " World";
String result = s1.concat(s2);
System.out.println(result); 
// Output: Hello World
split(String regex)
Arguments: 1

Splits this string around matches of the given regular expression.

import java.util.Arrays; // Needed for Arrays.toString()
String s = "apple,banana,orange";
String[] fruits = s.split(",");
System.out.println(Arrays.toString(fruits)); 
// Output: [apple, banana, orange]
split(String regex, int limit)
Arguments: 2

Splits this string around matches of the given regular expression with a limit on the number of times the pattern is applied.

import java.util.Arrays; // Needed for Arrays.toString()
String s = "a.b.c.d";
String[] parts = s.split("\\.", 2); // Split only once
System.out.println(Arrays.toString(parts)); 
// Output: [a, b.c.d]

Case & Whitespace Methods

toLowerCase()
Arguments: 0

Converts all of the characters in this String to lower case using the default locale.

String s = "HELLO";
String lower = s.toLowerCase();
System.out.println(lower); 
// Output: hello
toLowerCase(Locale locale)
Arguments: 1

Converts all of the characters in this String to lower case using the specified locale.

import java.util.Locale;
String s = "HELLO";
String lowerTurkish = s.toLowerCase(new Locale("tr", "TR")); // Turkish 'I' to lowercase 'ı'
System.out.println(lowerTurkish); 
// Output: helo
toUpperCase()
Arguments: 0

Converts all of the characters in this String to upper case using the default locale.

String s = "hello";
String upper = s.toUpperCase();
System.out.println(upper); 
// Output: HELLO
toUpperCase(Locale locale)
Arguments: 1

Converts all of the characters in this String to upper case using the specified locale.

import java.util.Locale;
String s = "istanbul";
String upperTurkish = s.toUpperCase(new Locale("tr", "TR")); // Turkish 'i' to uppercase 'İ'
System.out.println(upperTurkish); 
// Output: İSTANBUL
trim()
Arguments: 0

Returns a copy of the string, with leading and trailing ASCII whitespace omitted.

String s = "  Hello World  ";
String trimmed = s.trim();
System.out.println(trimmed); 
// Output: Hello World
strip()
Arguments: 0

Returns a string whose value is this string, with all leading and trailing whitespace removed (Java 11+). Handles Unicode whitespace.

String s = "  \t Hello World \n ";
String stripped = s.strip();
System.out.println(stripped); 
// Output: Hello World
stripLeading()
Arguments: 0

Removes all types of leading whitespace (Java 11+).

String s = "  \t Hello World ";
String stripped = s.stripLeading();
System.out.println("'" + stripped + "'"); 
// Output: 'Hello World '
stripTrailing()
Arguments: 0

Removes all types of trailing whitespace (Java 11+).

String s = " Hello World \n ";
String stripped = s.stripTrailing();
System.out.println("'" + stripped + "'"); 
// Output: ' Hello World'
stripIndent()
Arguments: 0

Removes incidental white space from each line of a multi-line string (Java 12+).

String text = "  Line 1\n    Line 2\n  Line 3";
String indented = text.stripIndent();
System.out.println(indented); 
// Output:
// Line 1
//   Line 2
// Line 3

Joining & Formatting Methods

join(CharSequence delimiter, CharSequence... elements)
Arguments: Varargs

Returns a new String composed of copies of the CharSequence elements joined together with a copy of the specified delimiter (static method).

String result = String.join("-", "Java", "is", "fun");
System.out.println(result); 
// Output: Java-is-fun
join(CharSequence delimiter, Iterable<? extends CharSequence> elements)
Arguments: 2

Returns a new String composed of copies of the CharSequence elements joined together with a copy of the specified delimiter (static method).

import java.util.Arrays;
import java.util.List;
List<String> words = Arrays.asList("hello", "world");
String joined = String.join(" ", words);
System.out.println(joined); 
// Output: hello world
format(String format, Object... args)
Arguments: Varargs

Returns a formatted string using the format specifiers (static method).

String name = "Alice";
int age = 30;
String formatted = String.format("Name: %s, Age: %d", name, age);
System.out.println(formatted); 
// Output: Name: Alice, Age: 30
format(Locale l, String format, Object... args)
Arguments: Varargs

Returns a formatted string with a specific locale (static method).

import java.util.Locale;
double value = 1234.56;
String formatted = String.format(Locale.US, "Value: %,.2f", value);
System.out.println(formatted); 
// Output: Value: 1,234.56
formatted(Object... args)
Arguments: Varargs

Returns a formatted string using the format string itself (instance method added in Java 15).

String template = "Hello %s, you are %d years old.";
String result = template.formatted("Bob", 25);
System.out.println(result); 
// Output: Hello Bob, you are 25 years old.

Conversion & Output Methods

toCharArray()
Arguments: 0

Converts this string to a new character array.

import java.util.Arrays; // Needed for Arrays.toString()
String s = "Java";
char[] chars = s.toCharArray();
System.out.println(Arrays.toString(chars)); 
// Output: [J, a, v, a]
getBytes()
Arguments: 0

Encodes this String into a sequence of bytes using the platform's default charset.

import java.util.Arrays;
String s = "hello";
byte[] bytes = s.getBytes();
System.out.println(Arrays.toString(bytes)); 
// Output: [104, 101, 108, 108, 111]
getBytes(Charset charset)
Arguments: 1

Encodes this String into a sequence of bytes using the given charset.

import java.nio.charset.StandardCharsets;
import java.util.Arrays;
String s = "hello";
byte[] bytes = s.getBytes(StandardCharsets.UTF_16);
System.out.println(Arrays.toString(bytes)); 
// Output: [-2, -1, 0, 104, 0, 101, 0, 108, 0, 108, 0, 111]
getBytes(String charsetName)
Arguments: 1

Encodes this String into a sequence of bytes using the named charset.

import java.io.UnsupportedEncodingException;
import java.util.Arrays;
String s = "hello";
try {
    byte[] bytes = s.getBytes("UTF-8");
    System.out.println(Arrays.toString(bytes)); 
} catch (UnsupportedEncodingException e) {
    e.printStackTrace();
}
// Output: [104, 101, 108, 108, 111]
getChars(int srcBegin, int srcEnd, char[] dst, int dstBegin)
Arguments: 4

Copies characters from this string into the destination character array.

import java.util.Arrays;
String s = "abcdef";
char[] dest = new char[10];
s.getChars(1, 4, dest, 0); // Copies 'bcd' from s to dest starting at index 0
System.out.println(Arrays.toString(dest)); 
// Output: [b, c, d, , , , , , , ]
toString()
Arguments: 0

Returns the string itself. Useful when overriding `toString()` in custom classes.

String s = "example";
String result = s.toString();
System.out.println(result); 
// Output: example
valueOf(boolean b)

String s = String.valueOf(true);
System.out.println(s);

valueOf(char c)

String s = String.valueOf('X');

char[] data = {'a', 'b', 'c'};

char[] data = {'x', 'y', 'z', 'w'};
String s = String.valueOf(data, 1, 2); // 'y', 'z'
System.out.println(s);

valueOf(double d)

String s = String.valueOf(3.14);

valueOf(float f)

Converts a float value to its string representation.

String s = String.valueOf(1.23f);

valueOf(int i)

Converts an int value to its string representation.

String s = String.valueOf(100);

valueOf(long l)

valueOf(Object obj)

Utility & Advanced Methods

lines()
Arguments: 0

Returns a stream of lines extracted from the string (Java 11+).

import java.util.stream.Collectors;
String multiLine = "Line1\nLine2\r\nLine3";
String result = multiLine.lines().collect(Collectors.joining(" | "));
System.out.println(result); 
// Output: Line1 | Line2 | Line3
hashCode()
Arguments: 0

Returns the hash code for the string.

String s = "Java";
System.out.println(s.hashCode()); 
// Output: 2301506
intern()
Arguments: 0

Returns a canonical representation for the string object. It returns a string from the string constant pool.

String s1 = new String("hello");
String s2 = "hello";
String s3 = s1.intern();
System.out.println(s1 == s2); 
// Output: false
System.out.println(s2 == s3); 
// Output: true
repeat(int count)
Arguments: 1

Returns a String whose value is the concatenation of this string repeated `count` times (Java 11+).

String s = "abc";
String repeated = s.repeat(3);
System.out.println(repeated); 
// Output: abcabcabc
indent(int n)
Arguments: 1

Adjusts the indentation of every line in this string (positive adds spaces, negative removes) (Java 12+).

String text = "Line 1\nLine 2";
String indented = text.indent(4);
System.out.println(indented); 
// Output:
//     Line 1
//     Line 2
describeConstable()
Arguments: 0

Returns an `Optional` describing this string constant, if it is a constant (Java 12+).

import java.util.Optional;
import java.lang.constant.Constable;
String s = "Hello";
Optional<Constable> constableDesc = s.describeConstable();
System.out.println(constableDesc); 
// Output: Optional[ConstableDesc[String[Hello]]]

translateEscapes()
Arguments: 0

Returns a string with escape sequences translated (Java 15+).

String escaped = "Hello\\nWorld\\t!";
String translated = escaped.translateEscapes();
